# Сравнение систем контроля версий: Git и SVN (Apache Subversion)

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
* **В Git:** Ветка — это легковесный указатель (файл размером всего 41 байт) на SHA-хеш коммита. Создание, переключение и слияние веток происходят мгновенно, так как Git оперирует графом объектов и снапшотов без физического дублирования файлов.
* **В SVN:** Создание ветки — это физическое создание копии каталога проекта на центральном сервере (`svn copy trunk/ branches/my-branch`). Это требует передачи данных по сети, занимает дисковое пространство на сервере и выполняется значительно медленнее.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?
* **Нет, нельзя.** SVN имеет централизованную архитектуру (CVCS). Локально у разработчика находится лишь рабочая копия (*working copy*) текущей ревизии, а вся база версий, история и журнал коммитов расположены исключительно на центральном сервере. Любая операция `svn commit` требует непосредственного сетевого подключения к серверу.
* **В отличие от SVN, Git распределён (DVCS):** каждый локальный репозиторий содержит полную копию всей истории и базы объектов, поэтому коммиты, создание веток и просмотр логов выполняются локально без интернета.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
1. **Работа с гигантскими бинарными ассетами:** В разработке игр (gamedev), 3D-графике и мультимедиа репозитории содержат тяжёлые непрозрачные бинарные файлы. SVN поддерживает частичное скачивание (*partial checkout*) поддиректорий без необходимости выкачивать всю историю проекта (в Git клонируется весь репозиторий, если не настроен LFS/sparse-checkout).
2. **Гранулярное разграничение прав доступа:** SVN позволяет гибко настраивать права на уровне отдельных папок и подпапок внутри одного репозитория (*Path-based authorization*). В Git права доступа выдаются только на весь репозиторий целиком.
3. **Legacy-инфраструктура:** Устаревшие государственные и банковские системы со строгими регламентами централизованного аудита, где миграция признана экономически нецелесообразной.
