# Преимущества Git в IDE (VS Code) vs Терминале (CLI)

## 3 вещи, которые удобнее делать в VS Code:
1. **Интерактивный просмотр диффов (Diff Viewer):** Наглядное построчное сравнение текущих изменений с предыдущей версией с подсветкой синтаксиса до добавления в staging area.
2. **Встроенный редактор merge-конфликтов:** Удобное разрешение коллизий одним кликом по кнопкам: «Accept Current Change», «Accept Incoming Change» или «Accept Both Changes».
3. **Визуализация авторства строк (расширение GitLens / git blame):** Мгновенная контекстная информация прямо в редакторе кода о том, кто, когда и в каком коммите/PR изменил конкретную строку.

## 1 вещь, которую удобнее делать в терминале (CLI):
1. **Сложные манипуляции с историей и автоматизация:** Выполнение интерактивного перемещения коммитов (`git rebase -i`), спасение коммитов через `git reflog`, выборочный перенос изменений (`git cherry-pick`), а также использование Git в CI/CD пайплайнах и bash-скриптах на удаленных серверах без графического интерфейса.
